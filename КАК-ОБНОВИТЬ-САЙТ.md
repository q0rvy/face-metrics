# Как обновить файлы сайта на GitHub Pages (исправление белого экрана)

Белый экран был из-за абсолютных путей (`/assets/…`, `/models/…`): на адресе
`q0rvy.github.io/face-metrics/` браузер искал файлы в корне домена и получал 404.
Эта версия собрана с относительными путями — работает и в подпапке, и в корне.

## Что заменить в репозитории

Замените ВСЁ содержимое репозитория `q0rvy/face-metrics` на содержимое этой папки
(старые `assets/index-*.js` и `assets/index-*.css` удалите — их имена изменились).

## Пошагово через сайт GitHub (без командной строки)

1. Зайдите в репозиторий **github.com/q0rvy/face-metrics**
2. **Удалите старую папку assets**: откройте `assets` → на каждом файле `…` → Delete →
   Commit (файлов всего 2–3). Или просто загрузите новые файлы поверх — а старые
   два (`index-DMgXq0G7.js`, `index-BXs_gx4p.css`) удалите после.
3. **Add file → Upload files** и перетащите всё содержимое этой папки:
   - `index.html` (заменится)
   - папки `assets`, `config`, `fonts` (в assets теперь 3 файла: js, css, шрифт)
   - `mediapipe-wasm` (5 файлов), `models`, `metric-imgs`, `guide`
   - папку `fonts` в корень класть НЕ нужно (шрифт теперь внутри assets) —
     если она у вас уже загружена, можно удалить
4. Commit changes
5. Подождите 1–3 минуты (Pages пересоберёт сайт) и откройте
   **https://q0rvy.github.io/face-metrics/**
6. Если всё ещё старая версия — сделайте Ctrl+F5 (жёсткое обновление, сброс кэша)

## Как убедиться, что версия правильная

Откройте исходный код страницы (Ctrl+U) — в новой версии пути выглядят так:

```html
<script type="module" crossorigin src="./assets/index-WZ9NcuLP.js"></script>
<link rel="stylesheet" crossorigin href="./assets/index-CyRwDAb3.css">
```

с точкой перед `/assets` (`./assets`). Если точки нет — грузится старая версия.

## Что изменилось внутри (для справки)

- все пути к ресурсам относительные (`./assets/…`, `./mediapipe-wasm`, `./models/…`,
  `./config/…`, `./guide/…`) — сайт работает на любом адресе, включая подпапку Pages
- шрифт Inter теперь в бандле (`assets/InterVariable-*.ttf`), отдельная папка
  `fonts/` не нужна
- убрана неиспользуемая копия wasm (`vision_wasm_module_internal.*`, −11 МБ)
- картинки метрик и гайдов пережаты без потери читаемости (2.1→1.4 МБ, 464→184 КБ)
- проверено в браузере под подпутём: конфиги, распознавание лица, таблица метрик
  и баллы работают
